# SynData 桌面端

Electron 桌面应用：剪贴板同步 + 文件传输。

## 开发运行

```bash
cd syndate/desktop
npm install
npm start
```

## 功能

- 📋 **剪贴板同步**：每 2 秒轮询服务器，检测到新剪贴板自动写入本地
- 📁 **文件传输**：选择文件加密上传；下载文件解密保存
- ⚙️ **设置持久化**：服务器地址、房间码自动保存（electron-store）

## 使用步骤

1. 启动应用 → 点右上角「⚙️ 设置」
2. 填写**服务器地址**（如 `http://服务器IP:8787`）和**房间码**
3. 点「连接」→ 状态变「✅ 已连接」
4. 剪贴板 / 文件功能即可使用

## 打包

```bash
# 本机构建当前平台安装包
npx electron-builder

# 三平台（由 CI 完成）
# push syndate/desktop/ 或手动触发 Actions
```

产物位置：`dist/`

## 加密说明

- 文本/文件在本地 AES-256-GCM 加密后上传
- 服务器只存密文，无法解密
- 房间码即密钥，两端需一致
